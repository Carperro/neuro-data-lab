# Neuro Data Lab

A self-directed learning project focused on building a scientific and computational foundation for exploring problems related to the brain, cognition, behavior and neuroscience.

## Areas of Study

* Programming
* Data Science
* Mathematics
* Statistics
* Neuroscience
* Technical English

## Objective

Build the computational, mathematical and statistical foundations necessary to eventually work with data related to neuroscience and the brain.

The project uses Python as the primary programming language and neuroscience as a progressive application domain.

## Academic Goal

The project is designed as preparation for the:

**Tecnicatura Universitaria en Ciencia de Datos — UNCUYO**

Start: **2026**

The first-year curriculum is used as a long-term roadmap rather than a rigid checklist.

The goal is to arrive at the degree with a strong foundation in Python, computational reasoning and technical English, allowing greater focus during the degree on mathematics, statistics, data science and other specialized subjects.

## Learning Philosophy

The project follows:

```text
UNDERSTAND
    ↓
REASON
    ↓
WRITE
    ↓
TEST
    ↓
DEBUG
    ↓
APPLY
    ↓
INTEGRATE
```

Priority:

```text
Understanding > Speed
Reasoning > Memorization
Practice > Passive consumption
Integration > Isolated topics
Building > Copying
```

The goal is not simply to make code work.

The goal is to understand why it works, identify problems independently, and progressively develop the ability to design solutions.

## Technical English

English is incorporated progressively into:

* Variables
* Function names
* Filenames
* Comments
* Technical terminology
* Documentation
* Programming concepts

Explanations remain primarily in Spanish while technical vocabulary gradually becomes English.
